<Callout type="warn">
	The debug panel is only accessible to accounts with the **`admin`** role. Regular players can't
	open it, and the shortcut does nothing for them.
</Callout>

FangDash ships with a hidden debug panel for maintainers. Use it to inspect live game state, confirm physics and difficulty values, and jump straight to the scenarios you need while testing.

## Open the panel

Press **Ctrl+Shift+D** during gameplay to toggle the panel on and off. Access is checked against your role — only `admin` accounts can open it.

The panel uses a CRT/retro terminal look — green-on-black text with scan lines — so it stays visually distinct from the main game UI and never gets mistaken for something a player should see.

## Tabs

The panel is split into three tabs.

### Stats

Live, per-frame game state:

- Current speed, score, and distance
- Frame rate and delta time
- The active difficulty tier

### Constants

The game constants currently driving the run, straight from `packages/shared`:

- Physics values (gravity, jump velocity)
- Speed and scoring multipliers
- Obstacle spawn rates

This is the fastest way to confirm a tuning change landed without digging through source.

### Cheats

Developer shortcuts for exercising specific scenarios:

- Set score or distance to a specific value
- Toggle invincibility
- Skip to a specific difficulty tier
- Force-trigger achievements
- **Unlock All Skins** — instantly unlocks every skin for the current player (calls `admin.unlockAllSkins`)

<Callout type="info">
	Cheats are testing aids, not a shortcut around progression. Runs that use them are handled like
	any other unverified run and don't earn ranked scores or XP — see
	[Scoring](/docs/gameplay/scoring) for how server-side validation works.
</Callout>
