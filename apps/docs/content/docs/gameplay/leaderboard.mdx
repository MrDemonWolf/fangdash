<Callout type="info">
	**TL;DR** — Filter by time period (Daily / Weekly / All Time) and difficulty (Easy → Nightmare).
	Only your personal best per filter is shown, so it's one entry per player. The top 3 earn gold,
	silver, and bronze badges.
</Callout>

The leaderboard ranks the best FangDash runs across every player. Open it anytime at [/leaderboard](/leaderboard). You need to [sign in with Twitch](/docs/getting-started) to appear on it — signing in is what saves your scores.

## Time period filters

Switch between three time windows to see who's fastest right now versus all-time greats:

| Filter       | Shows                          |
| ------------ | ------------------------------ |
| **Daily**    | Best scores from the last 24h  |
| **Weekly**   | Best scores from the last 7d   |
| **All Time** | The highest scores ever posted |

## Difficulty filtering

You can also filter by **difficulty tier**. Difficulty ramps up automatically with the distance you reach in a run, and each score is saved with the tier it was earned at — so you're always comparing like for like.

| Difficulty    | Distance threshold |
| ------------- | ------------------ |
| **Easy**      | 0m                 |
| **Medium**    | 500m               |
| **Hard**      | 1,500m             |
| **Insane**    | 3,000m             |
| **Nightmare** | 5,000m+            |

See [Difficulty](/docs/gameplay/difficulty) for the speed, spawn rate, and obstacle changes at each tier.

## Personal best

The leaderboard shows **one entry per player** — your single best score for the selected filters. Beat your own high score and your entry updates automatically. Only your top run counts, so grinding out attempts never clutters the board.

## Rank badges

The top 3 players earn a badge for the selected filters:

| Rank | Badge  |
| ---- | ------ |
| 1st  | Gold   |
| 2nd  | Silver |
| 3rd  | Bronze |

## What's excluded

Two things never show up on the board:

- **Cheated runs.** Every score is validated server-side before it can rank. Runs that exceed the theoretical maximum for their duration and obstacle count are flagged and excluded. They're still stored, but they earn no XP, stats, or leaderboard placement. See [Scoring](/docs/gameplay/scoring) for the exact ceiling.
- **Private profiles.** If you set your profile to private in [Account Settings](/docs/getting-started/settings), your scores stay off the public leaderboard. Flip it back to public any time to rejoin the rankings.

<Callout type="info">
	Want to climb faster? Higher difficulty tiers and stacked [mods](/docs/gameplay/mods) apply score
	multipliers, so a shorter, riskier run can outrank a long, safe one.
</Callout>
