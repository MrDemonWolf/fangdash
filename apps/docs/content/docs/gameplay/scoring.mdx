<Callout type="info">
	**TL;DR** — Earn 10 points/sec for surviving plus 50 points per obstacle cleared. Scores save
	**per difficulty**, and every point you score becomes **1 XP** toward your
	[level](/docs/gameplay/levels).
</Callout>

## Score formula

Your score comes from two sources:

| Source                | Points                        |
| --------------------- | ----------------------------- |
| **Time survived**     | 10 points per second          |
| **Obstacles cleared** | 50 points per obstacle dodged |

Your total is the sum of both. Distance is tracked separately (it accrues as your speed × 0.1) and feeds achievements and leaderboard stats rather than your score directly.

## Mod multiplier

If you turn on any [game mods](/docs/gameplay/mods) before a run, each active mod applies a **1.15× score multiplier**. Multipliers stack multiplicatively and are rounded to three decimals:

| Mods active | Multiplier |
| ----------- | ---------- |
| 1 mod       | 1.15×      |
| 2 mods      | 1.322×     |
| 3 mods      | 1.521×     |

The multiplier is applied to your base score, so a bigger challenge means more points. All three mods are ranked, so mod-boosted scores still count on the leaderboard.

## Per-difficulty scoring

Scores save with the **difficulty tier** you reached during that run. That lets the [leaderboard](/docs/gameplay/leaderboard) filter by difficulty, so your Easy runs compete against other Easy runs — not against Nightmare attempts.

## XP earning

Every point you score counts as **1 XP** toward your player level. Race placements add bonus XP on top of that: 1st place = 500 XP, 2nd = 250 XP, 3rd = 100 XP.

See [Level System](/docs/gameplay/levels) for the full curve.

## Tracked stats

Each score submission records:

| Stat                  | Description                                                                          |
| --------------------- | ------------------------------------------------------------------------------------ |
| **Score**             | Your total points                                                                    |
| **Distance**          | How far you ran (meters)                                                             |
| **Duration**          | How long the run lasted (seconds)                                                    |
| **Difficulty**        | The difficulty tier you reached                                                      |
| **Longest clean run** | Longest distance without hitting an obstacle (used for the Perfect Dash achievement) |

## Score validation

FangDash validates every score **on the server** so the leaderboard stays honest. When you submit a run:

<Steps>
	<Step>
		The server re-derives your ceiling from the run: roughly `((seconds × 10) + (obstacles × 50)) ×
		mod multiplier`, plus small tolerances. It also re-computes the mod multiplier itself so it
		can't be forged.
	</Step>
	<Step>
		Hard caps are enforced regardless: score up to 1,000,000, distance up to 200,000 m, obstacles up
		to 5,000, and a 30-minute maximum run length.
	</Step>
	<Step>
		Replays are blocked — each (player, seed) pair can only score once, so you can't resubmit the
		same run.
	</Step>
	<Step>
		After a valid score saves, the server checks for newly earned achievements and skin unlocks
		automatically.
	</Step>
</Steps>

<Callout type="warn">
	A run that exceeds its theoretical maximum is flagged as cheated. It's still stored, but it grants
	**no XP, no stats, and no unlocks**, and it never appears on the leaderboard.
</Callout>

To keep traffic fair, the API also rate-limits activity to 10 score submissions per minute and 60 read queries per minute per player.

## Leaderboards

The **global leaderboard** filters by time period (Daily / Weekly / All Time) and by difficulty tier, and shows only your personal best per filter combination. Cheated runs and private profiles are excluded.

See [Leaderboard](/docs/gameplay/leaderboard) for full details.
