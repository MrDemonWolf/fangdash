<Callout type="info">
	**TL;DR** — Mods are optional challenge toggles you pick on the Play screen before a run. Each
	active mod raises the difficulty and adds a **1.15x** score multiplier. Stack up to three and they
	multiply together for as much as **1.521x**. All three mods are ranked, so your scores still count
	on the leaderboard.
</Callout>

**Mods** are opt-in modifiers you enable before starting a run. Each one changes the game in a different way and rewards you with a bigger **score multiplier**. Leave them off for a clean run, or stack them to chase a higher number.

## Available mods

There are three mods, and every one is live right now. Fog is a visual challenge, while Headwind and Tremor both mess with your jumps and landings.

| Mod          | Icon | Category | Multiplier | Effect                                                        |
| ------------ | ---- | -------- | ---------- | ------------------------------------------------------------- |
| **Fog**      | 🌫️   | Visual   | 1.15x      | Visibility shrinks the farther you run. Can you run blind?    |
| **Headwind** | 💨   | Movement | 1.15x      | Wind shoves you down mid-air, growing stronger over distance. |
| **Tremor**   | 🌋   | Movement | 1.15x      | An earthquake shakes the ground, making landings harder.      |

## How the multiplier works

Your score multiplier is the **product** of every active mod's multiplier — mods stack multiplicatively, rounded to three decimals:

| Active mods | Multiplier |
| ----------- | ---------- |
| None        | 1.000x     |
| Any one mod | 1.150x     |
| Any two     | 1.322x     |
| All three   | 1.521x     |

Your final score is your base score times this value. The multiplier updates live on the Play screen as you toggle mods, and it is **re-derived and validated server-side** when your score saves, so it can't be forged.

## Ranked and beta mods

Mods can be flagged **beta** while they're still being tuned. Enabling a beta mod makes the run **unranked** — you can still play and see your score, but it **won't be submitted to the leaderboard**, and the Play screen flags this on any beta mod you pick.

Right now all three mods — Fog, Headwind, and Tremor — are **ranked**, so runs with any of them count on the leaderboard as normal.

## Mod-specific achievements

A few [achievements](/docs/customization/achievements) are tied to playing with mods on:

- **Fog Runner** — reach 2,000m in a single run with **Fog** enabled.
- **Headwind Hero** — score 5,000 in a single run with **Headwind** enabled.
- **Triple Threat** — score 3,000 in a single run with **all three** mods active.

## Tips

- Start with a single mod to learn how it changes your timing before you stack more.
- **Fog** punishes memorized patterns — it hides upcoming obstacles the deeper you get.
- **Headwind** and **Tremor** both attack your jumps, so running them together demands very precise landings for the 1.322x reward.
- Chasing **Triple Threat**? You'll need all three on at once, so practice each individually first.
