FangDash is a fast-paced multiplayer endless runner built for Twitch streamers and their communities. Race as a **wolf**, dodge procedurally generated obstacles, and compete for the highest score. It runs in your browser, it's MIT-licensed, and playing solo needs no account.

## What is FangDash?

Your wolf runs forward automatically. Jump over barriers, dodge hazards, and push as far as you can before you crash. The further you go, the faster and harder it gets across five difficulty tiers. In multiplayer, you and your Twitch chat race the exact same course at the same time — everyone sees identical obstacles, so it's fair by design.

## Features

| Feature                | Details                                                                      |
| ---------------------- | ---------------------------------------------------------------------------- |
| **Endless Runner**     | Jump, double-jump, and dash through procedurally generated courses           |
| **Multiplayer Racing** | Race up to 4 players in real time on one shared, seeded course               |
| **Twitch Integration** | Sign in with Twitch and race your chat                                       |
| **Wolf Skins**         | 6 skins (1 default + 5 unlockable) across five rarity tiers                  |
| **Achievements**       | 21 achievements across five categories                                       |
| **Level System**       | Earn XP from scores and race placements to level up                          |
| **Leaderboards**       | Filter by time period and difficulty, with server-side anti-cheat validation |
| **Difficulty Scaling** | Speed ramps from 300 up to 800 px/s as you run further                       |
| **Mods**               | Opt-in challenge modifiers (Fog, Headwind, Tremor) with score multipliers    |
| **Admin Panel**        | Manage players, moderate scores, and view race history                       |

## Play solo or sign in

You can jump straight into a solo run with no account. Signing in with Twitch saves your scores, XP, achievements, and unlocked skins — and it unlocks multiplayer racing. FangDash only uses Twitch as its sign-in provider.
