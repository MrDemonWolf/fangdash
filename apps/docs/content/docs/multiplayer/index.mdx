<Callout type="info">
	**TL;DR** — Race up to 4 players in real-time WebSocket rooms. Everyone runs the exact same course
	(shared seeded PRNG), rival "ghosts" show live positions, and finishing places earn bonus XP.
</Callout>

FangDash multiplayer pits you against up to 3 other players in real-time. Everyone runs the same obstacle course at once, and the highest score when the dust settles wins the race.

You need to be signed in with Twitch to race. Solo play works without an account, but multiplayer, saved scores, and XP all require signing in — see [Sign In](/docs/getting-started/sign-in).

## How to start a race

<Steps>
	<Step>From the main menu, open **Race**.</Step>
	<Step>Create a new room, or join an existing one with its room code.</Step>
	<Step>
		Wait for players to join. A room holds up to **4 players**, and a race can start once at least
		**2 players are ready**.
	</Step>
	<Step>
		When enough players are ready, a **3-second countdown** begins and everyone launches together.
	</Step>
</Steps>

The first player in a room is the **host**. If the host leaves, host duties migrate automatically to another player, so the room keeps running.

## Fair by design

Every racer faces the **exact same obstacles**. FangDash generates the course from a single shared seed using a seeded random number generator, so the layout is identical for everyone in the room — no player gets an easier run. Solo play uses its own separate seed.

Rooms move through four states as you play: **waiting → countdown → racing → finished**.

## What you see mid-race

During a race, other players appear as **ghosts** running alongside you. You can't collide with them, but you can watch their live progress and gauge how far ahead or behind you are. Solo runs don't have ghosts.

## Winning

The race runs until every player has crashed. Results are sorted by **highest score**, with earlier death time breaking any ties, and the standings are saved to race history with placements.

## Race XP bonuses

On top of the XP you earn from your score (1 point = 1 XP), your finishing place awards **bonus XP**:

| Placement | Bonus XP |
| --------- | -------- |
| 1st place | 500 XP   |
| 2nd place | 250 XP   |
| 3rd place | 100 XP   |
| 4th place | 0 XP     |

See the [Level System](/docs/gameplay/levels) for how XP and levels work, and check the [Achievements](/docs/gameplay/achievements) page for race-specific unlocks like Champion and Veteran Racer.
