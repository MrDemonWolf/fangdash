<Callout type="info">
	**TL;DR** — 21 achievements across 5 categories: Score, Distance, Games Played, Skill, and Social.
	Three of them unlock exclusive wolf skins, and progress tracks automatically — there's nothing to
	claim.
</Callout>

FangDash has **21 achievements** spread across 5 categories. Check your progress anytime at [/achievements](/achievements). You need to be signed in with Twitch to save achievement progress — see [Getting started](/docs) for how sign-in works.

## Score

Earn these by hitting **score milestones**. The first three count a single run; Score Hoarder adds up every run you play.

|     | Achievement   | Description                                    | Condition                  |
| --- | ------------- | ---------------------------------------------- | -------------------------- |
| 🐺  | First Fang    | Score 100 points in a single run               | Single-run score >= 100    |
| ⚡  | Sharp Fangs   | Score 1,000 points in a single run             | Single-run score >= 1,000  |
| 👑  | Apex Predator | Score 10,000 points in a single run            | Single-run score >= 10,000 |
| 💰  | Score Hoarder | Accumulate 50,000 total points across all runs | Total score >= 50,000      |

## Distance

Earn these by covering **long distances**. Distance climbs as you survive — the faster you go, the faster it stacks.

|     | Achievement     | Description                                | Condition                     |
| --- | --------------- | ------------------------------------------ | ----------------------------- |
| 🐾  | First Steps     | Reach 500 meters in a single run           | Single-run distance >= 500m   |
| 🏃  | Marathon Runner | Reach 5,000 meters in a single run         | Single-run distance >= 5,000m |
| 🌍  | World Traveler  | Travel 50,000 total meters across all runs | Total distance >= 50,000m     |

> **Skin reward:** 🏃 Marathon Runner unlocks the **Fire Wolf** skin.

## Games Played

Earn these just by **showing up and playing**. Every completed run counts.

|     | Achievement | Description          | Condition        |
| --- | ----------- | -------------------- | ---------------- |
| 🐶  | Pup         | Play your first game | 1 game played    |
| 🐺  | Pack Member | Play 25 games        | 25 games played  |
| 🌙  | Lone Wolf   | Play 100 games       | 100 games played |

## Skill

Earn these through **precise, clutch play** — clean runs, endurance, and pushing through [game modifiers](/docs/gameplay/mods).

|     | Achievement       | Description                                      | Condition                          |
| --- | ----------------- | ------------------------------------------------ | ---------------------------------- |
| 🔥  | Obstacle Dodger   | Clear 100 obstacles total                        | 100 obstacles cleared              |
| ⭐  | Obstacle Master   | Clear 1,000 obstacles total                      | 1,000 obstacles cleared            |
| 🛡️  | Obstacle Gauntlet | Clear 500 obstacles in a single run              | Single-run obstacles >= 500        |
| 💎  | Perfect Dash      | Survive a 1,000m run without hitting an obstacle | 1,000m clean run                   |
| ⏱️  | Endurance Wolf    | Survive for 120 seconds in a single run          | Single-run survival >= 120s        |
| 🌫️  | Fog Runner        | Reach 2,000m with the Fog mod on                 | 2,000m single run, Fog active      |
| 💨  | Headwind Hero     | Score 5,000 with the Headwind mod on             | Single-run score 5,000, Headwind   |
| 🌋  | Triple Threat     | Score 3,000 with all 3 mods on                   | Single-run score 3,000, all 3 mods |

> **Skin reward:** ⭐ Obstacle Master unlocks the **Storm Wolf** skin.

## Social

Earn these by **racing other wolves** in multiplayer. See [Racing](/docs/gameplay/racing) for how races work.

|     | Achievement   | Description            | Condition       |
| --- | ------------- | ---------------------- | --------------- |
| 🏁  | First Race    | Finish your first race | 1 race finished |
| 🏆  | Champion      | Win 10 races           | 10 races won    |
| 🎖️  | Veteran Racer | Play 50 races          | 50 races played |

> **Skin reward:** 🏆 Champion unlocks the **MrDemonWolf** skin.

## Achievements that reward skins

Three achievements hand you a wolf skin the moment you complete them — no separate unlock needed.

| Achievement        | Category | Skin reward |
| ------------------ | -------- | ----------- |
| 🏃 Marathon Runner | Distance | Fire Wolf   |
| ⭐ Obstacle Master | Skill    | Storm Wolf  |
| 🏆 Champion        | Social   | MrDemonWolf |

Want the full unlock list, including skins tied to raw milestones rather than achievements? See [Skins](/docs/customization/skins).
